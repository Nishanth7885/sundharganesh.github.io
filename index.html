The Project That Earned the Promotion

CI/CD Pipeline Automation using Gitea and Jenkins

Gitea Jenkins Git Docker Linux
Problem

Manual copy and paste deployments at a 24/7 hospital created release risk, audit gaps, and slow recovery when something broke in production.

Action
  • Implemented self-hosted CI/CD using Gitea and Jenkins to modernize legacy deployment workflows.
  • Configured Gitea repositories and Jenkins pipelines triggered through Git push events with approval based production gates.
  • Trained development teams on Git workflows and standardized deployment practices across the organization.
Outcome

Replaced manual copy and paste deployments with reviewable, repeatable, Git driven pipelines. Reduced deployment time, minimized human error, and gave the team an audit trail for every release.
